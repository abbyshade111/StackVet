# ADR-088: Four credits and gaps the part 4 audit found wrong, corrected

**Status:** accepted, 11 October 2026, at the owner's word ("yes, fix the four defects"), in the pull request that makes the
fixes (backlog 0006, part 4).

**Governs:** `crates/sv-check/src/model_files.rs`, `crates/sv-check/src/ai.rs::KILL_SWITCH`, `crates/sv-check/src/ai.rs::kill_switch`. The other three corrections are recorded in ADR-053 (Later, 11 October 2026,
the admin action) and ADR-067 (Later, 11 October 2026, the private pages), and the kill-switch correction in ADR-088's own
text below.

## Context

The part 4 audit read every plain credit (a "checked" that gives one sample, or a check that gives a pass) against the
rule that something not assessed is never a pass. Four were wrong, each in a different way.

## Decision

1. **The kill-switch credit (C9.6.1, `ai.rs`) needs an answer below 500.** It was given for any HTTP answer, including a
   server error, which cannot be told from a copy that crashed. The rule is now the one C2.1.3 uses (200 to 499 answers the
   request). A server error is said as not assessed, with the status. A feature that is off should answer below 500.
2. **A listed private page that does not open is said, and puts the credits in part.** The page checks skipped a listed
   page with no gap in the report. Now each skipped page is reported as not assessed under the requirements its checks cover,
   and the three page credits are in part whenever a listed page was skipped, since not every listed page was checked.
3. **The model-file check does not pass when a large file was not read whole.** A model-named file too large to walk could
   hold an old pickle. When none of the files read holds one, but some were not read whole, the check says so as not
   assessed, and does not credit a pass.
4. **The admin-action credit (ADR-053) is given only when every listed action was judged and confirmed as the admin's own.**
   It was given when one action was refused, even if another action never posted for the admin. It now matches the
   admin-page credit: each action must be judged and confirmed, and one listed action is in part.

## Consequences

- Some apps that were credited in full are now credited in part, or not assessed, for the reasons above. Nothing that a
  correct app earned is taken away; a correct app with one listed action now reads "in part", as one listed page does.
- A kill switch that answers with a server error is not a pass until it answers below 500.

Governs: this record is new. ADR-053 and ADR-067 have dated entries for the admin and private-page corrections. The records
that govern `ai.rs` (ADR-071, ADR-073, ADR-074, ADR-075, ADR-079) are unchanged, because their checks are not altered; the
kill-switch correction is recorded here.
