# ADR-136: A Rust module that is compiled only for tests is read as test code

**Status:** proposed, 23 October 2026, with the claim for backlog 0644, from the triage of StackVet's
findings on its own repository (backlog 0633), which asks that a rule found wrong is fixed, with a test that it
still fires where it should. It becomes accepted in the pull request that builds it.

**Governs:** while proposed, the claim it is made with, `docs/backlog/0644-a-rust-module-compiled-only-for-tests-is-not-read-as-test.md`; the pull request that builds it
replaces that with the files it changes. A pull request that changes how a Rust file is read as test code changes this record too,
or says in its description why it does not (`docs/adr/README.md`).

## Context

A finding in test code still counts, and the report says beside it that it is in test code (ADR-023). A few rules'
findings in test code are information instead (ADR-091, backlog 0529). `sv` reads Rust test code by a `tests` folder
or by `#[cfg(test)]` and `#[test]` lines inside a file (`crates/sv-check/src/finding.rs`, `mark_rust_test_code`). A
module that is a file of its own, declared `#[cfg(test)] mod name;` or `#[cfg(test)] #[path = "x.rs"] mod name;`, is
neither, so its findings read as the app's own. In StackVet's report on itself that was 142 path findings and 9 test
passwords.

## Decision

- **A file is test code when the app declares it as a module under `#[cfg(test)]`:** `#[path = "..."]` resolved from the
  declaring file's folder, or `name.rs` or `name/mod.rs` beside it, as Rust finds them. The declaring line is the
  evidence: Rust compiles that file only for its tests.
- **Only what Rust itself would do.** A module without `#[cfg(test)]`, a file no declaration names, or one declared
  inside a `mod` block whose own folder this does not follow, is read as before.
- **Test code still counts.** This changes what is said beside a finding, and which of the information rules apply,
  never whether a finding counts.
- Held by tests of each form, and of a module without `#[cfg(test)]`.
