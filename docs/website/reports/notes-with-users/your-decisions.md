## Requirements nobody has placed

Each of these applies or not depending on an answer only you can give. Answer it in `stackvet.toml`, or with your AI coding tool, and write the report again.

- **AC.11.7** Verify that AI review bots run in a zero-privilege, read-only shadow mode for untrusted fork PRs.
